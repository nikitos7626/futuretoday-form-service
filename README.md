# Сервис создания форм откликов и телеметрии в реальном времени

Сервис на чистом Node.js (Express) с хранением данных в SQLite, позволяющий администраторам создавать опросы/формы с кастомными URL-ссылками, а участникам заполнять их с автоматическим сохранением состояния и телеметрией после каждого изменения.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm i
```

### 2. Запуск приложения
```bash
npm start
```

После запуска сервис доступен по адресу:
- **Главная страница / Панель администратора**: [http://localhost:3000/admin](http://localhost:3000/admin)
- **Формы участников**: `http://localhost:3000/s/<кастомный-slug>`

---

## ⚙️ Конфигурация (.env)

Файл `.env` расположен в корне проекта:
```env
PORT=3000
```
Если переменная `PORT` не задана, по умолчанию используется порт `3000`.

## 🧩 Основные возможности

1. **Панель создания опросов (`/admin`)**:
   - Настройка названия и описания опроса.
   - Задание кастомного URL-слага (например, `/s/conference-feedback` или генерация случайного слага в 1 клик).
   - Динамический конструктор вопросов с поддержкой типов:
     - Обычный текст (`text`)
     - Развернутый ответ (`textarea`)
     - Оценка от 1 до 5 (`rating`)
     - Число (`number`)
     - Один вариант из списка (`single` / radio)
     - Несколько вариантов из списка (`multiple` / checkbox)
     - Опция обязательного вопроса.
   - Быстрое копирование ссылки в буфер обмена.

2. **Форма отклика участника (`/s/:slug` или `/survey/:slug`)**:
   - Динамический рендеринг формы опроса.
   - Восстановление и сохранение сессии через `localStorage`.
   - **Автосохранение и телеметрия в реальном времени**: каждый ввод текста, выбор варианта или клик по оценке немедленно отправляет телеметрию и сохраняет текущее состояние ответов в SQLite.
   - Индикатор статуса: *«Сохранение...»* ➔ *«Сохранено (время)»*.
   - Индикатор прогресса в процентах.

3. **Телеметрия карточек и опрос в реальном времени**:
   - Администратор может открыть дашборд телеметрии любого опроса в `/admin`.
   - Автоматический опрос карточек каждые 2 секунды (с возможностью принудительного опроса).
   - В карточке каждого респондента в реальном времени отображаются:
     - Имя / идентификатор сессии.
     - Текущий статус (*«Заполняет»* / *«Отправлен»*).
     - Прогресс заполнения карточки (0–100%).
     - Количество зафиксированных изменений (`change_count`).
     - Последнее измененное поле и время обновления.
     - Текущие введенные ответы прямо из SQLite.
     - История последних событий телеметрии.

## 📡 API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/admin` | Панель администратора |
| `GET` | `/s/:slug` | Форма отклика для участников |
| `POST` | `/api/surveys` | Создание опроса и генерация ссылки |
| `GET` | `/api/surveys` | Список опросов и статистика откликов |
| `GET` | `/api/surveys/:slug` | Получение конфигурации опроса |
| `DELETE` | `/api/surveys/:slug` | Удаление опроса |
| `POST` | `/api/surveys/:slug/session` | Инициализация / возобновление сессии участника |
| `POST` | `/api/surveys/:slug/telemetry` | Сохранение текущего результата после каждого изменения |
| `GET` | `/api/surveys/:slug/telemetry/:sessionId` | Опрашивание состояния отдельной карточки |
| `GET` | `/api/surveys/:slug/responses` | Опрашивание всех карточек и телеметрии для админки |
| `POST` | `/api/surveys/:slug/submit` | Финализация и отправка отклика |

## 🧪 Запуск тестов

Тесты написаны с использованием встроенного тест-раннера Node.js (`node:test` и `node:assert`):
```bash
npm test
```
Тесты проверяют полный цикл: создание опросов, генерацию ссылок, сессии, телеметрию при каждом изменении, опрос карточек и отправку.
