**Проект:** Сервис создания форм откликов с live-телеметрией  
**Использованная модель:** Gemini 3.8 Flash (High)  

## Использованные специализированные AI-скиллы (Skills)

Для обеспечения строгой инженерной дисциплины  в проект были интегрированы два ключевых скилла:

1. **[ub-mode](https://github.com/unclebob/ub-mode)**
   * **Назначение:** Реализация редуцированных инженерных принципов Роберта Мартина (Дядюшки Боба): *First Make it Work -> Then Make it Right -> Follow Practice*.
   * **Роль в проекте:** Контроль сложности, отсечение избыточных абстракций, строгое следование TDD (тест перед фиксом) и поэтапный рефакторинг в чистый MVC без изменения внешнего поведения.

2. **[hallmark](https://github.com/nutlope/hallmark)**
   * **Назначение:** Anti-AI-slop дизайн-система от Together AI / Nutlope, исключающая «нейросетевой мусор» в интерфейсах (градиенты, размытые тени, избыточные библиотеки компонентов).
   * **Роль в проекте:** Создание легковесного, строгого и контрастного интерфейса на чистом CSS (тема **Cobalt** с `IBM Plex Sans`, палитрой `oklch`, токенами в `:root` и физическими keycaps-кнопками для шкал оценки) без необходимости подключения React/Tailwind/Bootstrap.

### Сообщение 12 
```text
/ub-mode Then Make it Right: Рефакторинг архитектуры в классический MVC

Сейчас surveyService.js и app.js разрослись до 500+ строк и совмещают работу с базой, валидацию и роутинг. Давай разложим бэкенд по прозрачной структуре MVC без оверинжиниринга:

1. Создай папку src/models/:
   - surveyModel.js: чистые SQL-запросы для анкет (создание, поиск по slug, поиск по content_hash, обновление, удаление, список).
   - responseModel.js: SQL-запросы для откликов соискателей (создание/получение сессии по session_uuid, автосохранение телеметрии, сабмит, агрегация аналитики отвалов).

2. Создай папку src/controllers/:
   - surveyController.js: обработчики HTTP-запросов (req, res) для анкет (вызовы surveyModel, обработка дубликатов по хэшу).
   - responseController.js: обработчики для соискателя (сессия, телеметрия, завершение анкеты).

3. Создай папку src/routes/:
   - apiRoutes.js: чистая карта эндпоинтов, привязанных к методам контроллеров.

4. Вынеси утилиту хэширования:
   - src/utils/hash.js: computeSurveyHash (канонизация структуры и SHA-256).

5. Сократи src/app.js:
   - Файл должен стать компактным (~35 строк): только настройка express.json, раздача static из public, подключение apiRoutes и редиректы.

ГЛАВНОЕ ТРЕБОВАНИЕ:
Не меняй контракты API и сигнатуры ответов! После разделения все тесты (npm test) должны проходить на 100% без ошибок.

Зафиксируй в git-коммите: "refactor: decompose monolithic service into clean MVC architecture".
```
